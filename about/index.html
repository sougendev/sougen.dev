開発中のサービス

タナマル / Tanamaru

開発中 · 一般向け提供を準備中

「売れた商品が、どこにあるか」をすぐに確認できる在庫・保管管理サービス。自宅や小さな倉庫で商品を扱う、個人・小規模のフリマ販売者に向けて開発しています。

Claude API を使った出品文の下書き生成を開発予定です。この機能はまだ提供していません。一般向けの提供時期と料金は未定です。

About sougen

sougen (Sougen Dev) is an independent software business operating as a sole proprietorship, started in September 2026. The business develops software for individual and small resale sellers.

Its current product, Tanamaru, is an inventory and storage management tool being developed from firsthand selling experience. It connects item records, photos, storage locations, shelf and box capacity, and sales status. The development version is used in the operator's own selling workflow. Public availability and pricing are yet to be determined; early-access interest is being collected.

A Claude API integration for drafting Japanese listing descriptions is planned and is not yet available.
